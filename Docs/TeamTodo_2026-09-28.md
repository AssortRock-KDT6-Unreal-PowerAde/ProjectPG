## 1. 캐릭터·몬스터쪽 필요 부분

**① 맞으면 체력이 줄고, 0 이 되면 죽게**
- 지금: 체력 숫자는 있는데 깎는 코드가 없어서, 총·몬스터·폭발에 맞아도 안 죽습니다.
- 할 일: 플레이어 캐릭터의 `TakeDamage` 에서 체력을 깎아 주세요. (공격 쪽과 "죽으면 판 끝" 쪽은 준비돼 있습니다.)
- 확인: 서버 콘솔에 `PG.DamagePlayer 0 30` → 로그에 `Health 100 -> 70` 이 나오면 됩니다.

**② 플레이어끼리 서로 때릴 수 있게 할지 정하기**
- 기획에서 정해야 합니다. 정해지면 한 곳(게임 모드)에서만 막거나 풀면 됩니다.
- 확인: `PG.DamagePlayer 0 30 1` (1번 사람이 0번을 쏜 것처럼).

**③ 제가 임시로 고친 플레이어 코드 3곳을 형님 코드로 옮기기**
- 안 고치면: 멀티에서 상대 캐릭터가 서 있는데 걷는 동작을 하고, 걸을 때 뚝뚝 끊깁니다.
- 확인: 2명 멀티에서 가만히 서 있을 때 서 있는 동작이면 됩니다.

**④ 제가 임시로 고친 몬스터 코드(공격·맞는 동작)를 형님 코드로 옮기기**
- 안 고치면: 멀티에서 몬스터가 휘두르는 동작 없이 피해만 줍니다.
- 참고: 제 탑승 로봇도 같은 함수(`PlayOnceForAll`)를 씁니다. 이름을 바꾸시면 알려 주세요.

**⑤ 달리기가 멀티에서 끊기지 않는지 한 번 확인**
- 2명 멀티에서 달려 보시면 됩니다.

## 2. 서버·UI쪽 필요 부분

**① 매칭 서버 켜고, 출격 누르면 같은 판에 모이는지 확인**
- 로비 "출격" → 형님 매칭 요청 → "매칭 중…" 표시까지는 연결해 뒀습니다.
- 매칭 서버가 없어서 거기부터는 확인을 못 했습니다.
- 확인: 2~4명 로그인 → 출격 → 같은 판에 들어가면 됩니다.

**② 주운 아이템이 접속자 가방에도 보이게**
- 지금: 멀티에서 아이템을 주우면 서버 가방에만 들어가고, 접속자 가방 창은 비어 있습니다.
  (탈출·연료통 판정은 서버 가방으로 해서 게임은 돌아가지만, "가방에 없는데?" 하고 헷갈립니다.)
- 확인: 서버 `PG.Delay 35 PG.SpawnGirl`, 접속자 `PG.GirlSpamTest` → 접속자 로그에 `bag Fuel=1` 이 나오면 됩니다.

**③ 창고·기록을 사람마다 따로 저장**
- 지금: 그 컴퓨터 파일에 저장해서, 한 컴퓨터에서 두 명을 켜면 기록이 똑같이 보입니다.
- 할 일: 로그인 서버에 계정별로 저장. `UPGRunSubsystem` 의 저장·불러오기 두 함수만 바꾸면 됩니다.

**④ 알아 두실 것**
- 타이틀의 "서버 연결 안 됨 — 오프라인으로 시작" 은 웹 서버가 꺼져 있을 때 나오는 버튼입니다. 켜지면 안 나옵니다.
- 전용 서버는 `LD_MetaballGenerationTest` 맵으로 켜면 됩니다. `-PGMapSeed=숫자` 를 붙이면 매번 같은 맵이 나옵니다.
- 매칭 없이 시험할 때는 접속하는 쪽 실행 인자에 `-PGServer=주소:포트` 를 붙이면 그 서버로 바로 들어갑니다.
- 타이틀·로비·결과·설정 화면은 전부 위젯 블루프린트(`Content/PG/UI`)라, 코드 없이 모양을 바꿀 수 있습니다.
