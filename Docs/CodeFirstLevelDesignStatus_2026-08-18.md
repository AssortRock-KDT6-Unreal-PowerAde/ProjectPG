# 코드 중심 절차적 레벨 디자인 상태 — 2026-08-18

## 현재 결론

`ProjectPG`의 레벨 디자인은 형님의 논리 타일 생성 결과를 유지하면서, 그 위에 코드가 시각 타일과 다중 셀 시설을 조립하는 구조다. 싱글 PIE에서 전체 30×30 논리 셀을 생성하고, 이후 서버가 동일한 Seed와 배치 목록을 전달하는 방식으로 확장할 수 있다.

원본 `D:\ProjectPG`는 수정하지 않았다.

## 코드가 담당하는 것

- `AGameModePG`가 형님 코드의 논리 맵을 먼저 생성한다.
- 논리 `AMapTile`은 데이터로 유지하되 첫 프레임부터 화면과 충돌에서 숨긴다.
- `AWarZoneFootprintPreview`가 논리 셀을 읽어 20×20m 시각 타일, 시설, 게임플레이 포인트를 결정한다.
- `ATacticalTileActor`가 1×1 자연·도로·폐허·WarZone 타일을 Seed 기반으로 구성한다.
- `AProceduralFacilityActor`가 Blueprint 없이 C++로 다중 셀 시설을 구성한다.

## 코드 시설 규격

| 시설 | 논리 크기 | 실제 크기 | 용도 |
|---|---:|---:|---|
| IndustrialRaid3x3 | 3×3 | 60×60m | 중앙 WarZone, 2층/캣워크, 주 전투 시설 |
| SatelliteCamp2x2 | 2×2 | 40×40m | 위성 캠프·보조 POI |
| LongBarracks2x1 | 2×1 | 40×20m | 긴 막사·실내 교전 |
| LinearTrench4x1 | 4×1 | 80×20m | 선형 엄폐·참호 교전 |

시설은 Entrance, Loot, UpperLoot, AI 소켓을 코드 컴포넌트로 제공한다. 중앙 3×3 시설은 WarZone 중앙에 우선 배치하고, 나머지는 동일 구역 안에서 겹침 없이 결정한다.

## 레벨아트 수직성 패스

- 모든 20×20m 타일의 네 연결부는 공통 Z=0을 유지한다. 따라서 높이 변화가 추가되어도 Road 소켓과 서버 Manifest 조립 규칙은 변하지 않는다.
- NatureRocky 일부 변형과 WarZone Yard/Warehouse 일부 변형에는 타일 내부의 0.9~1.15m 전술 고지대, 실제 계단, 양방향 암석 엄폐가 생긴다.
- NatureDitch의 직사각형 대형 벽은 낮고 끊어진 둑 8개와 횡단 지점 4개로 교체했다.
- IndustrialRaid3x3에는 Z=3.3m 상부 연결교, 양측 난간, Z=6.6m 지붕을 가진 상부 제어실 두 곳을 추가했다.
- SatelliteCamp2x2에는 Z=2.8m 관측 데크와 계단을 추가하고 UpperLoot 소켓을 데크로 이동했다.
- LongBarracks2x1은 실내 교전을 위한 완전한 지붕을 갖는다.
- 계단·난간은 Factory Pack, 암석은 Downtown West의 실제 메시를 사용한다. 기존 Blueprint에 저장되어 있던 작은 Rock_1 메시도 런타임에 Downtown 암석으로 정규화한다.
- 수직 구조는 타일 바깥 6m 이내로 접근하지 않게 구성해 이웃 셀과의 경계·회전·접속 규칙을 그대로 보존한다.

## 게임플레이 포인트

- Spawn, Loot, AI, Exit에 Quest가 추가되었다.
- 시설별 Loot/AI 포인트가 최소 한 개 이상 생성된다.
- 중앙 시설에는 주 목표, 일부 막사에는 Seed 기반 선택 목표가 생성된다.
- 포인트는 충돌 안전성, 분포, 논리 경로 도달성을 PIE에서 자동 검사한다.

## Maze와 이동 가독성

- 형님 코드의 논리 연결성과 Road는 변경하지 않는다.
- Maze 구역은 5셀 단위의 숲·암석 장벽 띠로 시각화한다.
- 도로와 실제 통과 셀, 그 주변 2셀은 장벽에서 제외해 경로를 막지 않는다.
- WarZone 산업 소품은 이음새를 넘겨 연속된 구역처럼 보이게 할 수 있지만, 구조 벽은 엄격한 타일 경계 검사를 유지한다.

## 멀티플레이 전달 기준

서버가 복제해야 할 최소 배치 정보는 다음과 같다.

- ManifestVersion
- MapSeed
- CellX, CellY
- TileKind 또는 FacilityKind 이름
- FootprintX, FootprintY
- RotationQuarterTurns
- VariantSeed

enum의 숫자값을 그대로 저장하지 말고 이름 또는 버전이 붙은 안정 ID를 사용한다. 정적인 메시와 풀은 클라이언트가 동일 Manifest로 로컬 생성하고, 문·루팅·파괴물처럼 상태가 바뀌는 액터만 별도 복제한다.

- IndustrialRaid3x3의 네 변형은 상부 연결교 Y 위치, 좌우 제어실 위치, 양쪽 계단 접근 방향, 지상 컨테이너·엄폐 군집이 서로 다르다.
