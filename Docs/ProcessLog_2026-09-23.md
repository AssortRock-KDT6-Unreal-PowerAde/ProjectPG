### 2-6. 멀티플레이 — 전용 서버 + 접속자 (9/26~9/28)

기획은 처음부터 멀티였는데, 기능마다 혼자 하는 판으로만 확인해 와서 "서버에서만 바뀌고 접속자 화면에는 안 보이는" 것이 쌓여 있었다.
그래서 **"접속자 화면에서 확인해야 됐다"** 를 규칙으로 삼고, 화면 없는 서버 + 접속자 시험 도구를 만들어 하나씩 쟀다.

## 4. 배운 것

1. **재고 나서 고친다.** 잔해 81ms 는 Insights 로 NarrowPhase 를 찍은 뒤에 풀렸다. 붕괴는 엔진 소스를 열어 비용을 확인한 뒤 설계를 바꿨다.
2. **'확신에 찬 0' 을 의심한다.** 레이 12만 개의 '겹침 0' 은 거짓이었다. AI 첫 비교는 측정 조건이 불공평했다.
3. **경계를 좁힌다.** 팀원 생성기는 계약으로, 인벤토리는 인터페이스 4함수로. 서로 코드를 고치지 않고 합쳤다.
4. **같은지 증명한다.** 리팩토링의 정답은 '이전과 같다' — 시드 고정 실행, 로그·캡처 비교, 자동 검사 64개.
5. **안전장치도 틀릴 수 있다.** 탐지 실패 때의 '안전값'(200m 고도), 굽는 중인 메시의 크기가 오히려 버그를 만들었다.
6. **"누구 화면에 보여야 하나" 부터 정한다.** 혼자 하는 판에서는 서버 = 내 화면이라 복제 누락이 절대 안 보인다. 멀티 게임은 접속자 화면에서 재야 끝난다.
7. **느린 곳을 나눠 잰다.** 끊김이 계산인지 그리기인지 먼저 갈랐다(게임·렌더·GPU 시간). 부수기 계산은 프레임당 1ms 였고, 진짜 원인은 그림자 전등 52개였다.
