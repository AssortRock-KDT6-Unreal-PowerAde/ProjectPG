# RTX 4060 8GB 기준 측정 (2026-09-28)

목표 사양은 RTX 4060 8GB 입니다. 집 PC(RTX 5060 Ti 16GB)에서 **전용 서버 + 화면을 실제로 그리는 접속자 1명(1920x1080)** 으로 장면마다 재고,
GPU 시간은 4060 기준으로 환산했습니다.

- **4060 환산:** 공개 벤치마크로 5060 Ti 가 4060 Ti 보다 약 13~20%, 4060 Ti 가 4060 보다 약 20% 빠릅니다 → 약 1.4배. **넉넉하게 x1.5** 로 봤습니다.
  (추정입니다. 4060 PC 에서 같은 스크립트를 돌리면 실제 값이 나옵니다 — 아래 "다시 재는 법".)
- **VRAM:** 윈도우 GPU 카운터로 접속자 프로세스가 쓰는 전용 메모리를 2초마다 쟀습니다. 텍스처 한도는 학원 PC 와 같은 1.5GB(`r.Streaming.PoolSize=1500`).
- 사람이 선 뒤 **처음 20초는 따로** 봅니다(맵 마무리·첫 셰이더). 표의 평균은 그 뒤입니다.

## 결과 (고친 뒤)

| 장면 | 이 PC fps | GPU 평균 / 95% | **4060 추정 fps (평균 / 95%)** | VRAM 최대 | 가장 긴 프레임 |
|---|---|---|---|---|---|
| 시작 지역에 서 있기 | 77 | 6.7 / 7.5 ms | **100 / 89** | 3.8GB | 45ms |
| 차로 비행 | 96 | 6.9 / 7.9 ms | **96 / 84** | 4.0GB | 41ms |
| 8배 로봇으로 중앙 건물 부수기 | 96 | 7.1 / 8.5 ms | **94 / 78** | 4.1GB | 48ms |
| 전함 갑판에서 드래곤 등장 + 땅 붕괴 | 90 | 9.0 / 11.2 ms | **74 / 60** | 4.2GB | 46ms |

- VRAM 은 최대 4.3GB — 8GB 안에 넉넉합니다.
- 처음 20초는 이 PC 에서 60~66fps(4060 에서는 더 낮을 것). 로딩 화면이 걷힌 직후 잠깐입니다.
- 이 PC 가 서버와 접속자를 같이 돌려서 CPU 쪽(렌더 스레드) 숫자는 실제보다 나쁘게 나왔을 수 있습니다.

## 고친 것

- **드래곤 등장 땅 붕괴**: 움직이던 8,058개 중 7,463개가 풀 덤불이었다(`PGCollapse: by mesh` 로그). 풀·덤불은 움직이지 않고 흙먼지 속에서
  사라지게 하고, 바닥판·나무·바위·벽만 무너뜨린다 → 움직이는 조각 557개, 붕괴 3초 동안 가장 긴 프레임 68 → 19.7ms(순간 최저 15 → 51fps).
- **CPU 그리기 준비(그리기 호출)**: CSV 프로파일(`csvprofile frames=300`, 비교 `Tools/wbp/csv_compare.py`)로 봄. `PG.ISMReport 40 sm`(보통 메시 순위)으로
  바닥 아이템(탄약 914·권총 216·무기 수백 개)이 각각 따로, 거리 제한 없이 그려지는 것을 찾음 →
  ① 상호작용 오브젝트 메시에 크기별 보이는 거리(작은 것 60m, 중간 120m — `DA_PGMapVisuals` 의 `SmallObjectDrawDistanceCm`/`MediumObjectDrawDistanceCm`),
  ② 많이 깔린 불투명 메시 23종 나나이트 켬(CQB 벽 6·공장 울타리·우리 바닥 무기/모자/조끼/연료통·탈출 부스·탱크·탄약/약 상자).
  그리기 호출 4,019 → 1,663번, 렌더 스레드 12.6 → 10.4ms(이 PC, 서버 같이 실행).
- **스폰 직후 끊김**: 로딩 화면이 걷힌 뒤 10초 동안 시설 레벨(중앙 건물·시가지)이 아직 올라오는 중이라 0.1~0.4초 멈춤이 이어졌다 →
  시설 레벨이 다 올라와 보일 때까지(최대 20초) 로딩 화면을 둔다(`AWarZoneFootprintPreview::HideLoadingWhenFacilitiesVisible`).
  걷힌 뒤 80ms 넘는 프레임 0번(로딩은 8~10초 더 길어짐, 혼자 하는 판은 3.5초).
- 풀 묶음(10만 개 넘는 마스크 카드)은 두 번째로 무거웠지만 위 셋으로 충분해서 그대로 뒀습니다. 느린 PC 에서 줄일 첫 손잡이로 거리 값을
  `DA_PGMapVisuals` 의 `RuntimeGrassFadeStartCm` / `RuntimeGrassCullEndCm`(기본 18m / 60m)로 옮겼습니다.
- 에셋 팩 파일이 바뀌었습니다(Fab 자동차, ControlRig 마네킹, Paragon Rampage) — 드라이브 zip 도 다시 만들었습니다.

## 다시 재는 법

에디터를 끄고:

```
powershell -File Tools/wbp/perf_4060.ps1 [-Seed 12345]
```

네 장면을 차례로 돌리고 `Tools/wbp/perf_summary.py` 가 이 표를 찍습니다. 4060 PC 에서 돌리면 `python Tools/wbp/perf_summary.py <폴더> 1` 로 환산 없이 봅니다.
도구: `PG.PerfLog`(1초마다 fps·GPU·텍스처 메모리), `PG.AfterReady <초> <명령>`(사람이 선 뒤 명령, 예: ProfileGPU), `PG.ISMReport`(인스턴스 메시 무게 순위).
